Block Quest 3D

Desktop : ZQSD / WASD, E pour interagir, espace pour sauter.

Mobile : joystick à gauche, E pour interagir, ↑ pour sauter.

Bienvenue dans Block Quest 3D

Tu es dans un monde 3D voxel inspiré de Minecraft. Explore la map, trouve les trois cristaux et réactive le portail du village.

Tout tient dans un seul index.html, prêt à être déployé sur Vercel.

Victoire

Tu as récupéré tous les cristaux et réactivé le portail.

Cette base peut maintenant évoluer vers un vrai mini-jeu complet.
